
# Evaluating Mathematical Reasoning in LLMs

A planned set of mathematics problems for testing how well language
models reason: not just whether they reach the right answer, but
where and how their reasoning breaks down.

Each problem will include a worked solution and notes on the specific
reasoning step that tends to fail. 

Built and graded by Magnus Hellstrøm-Finnsen, PhD in mathematics (NTNU), mhellstroemfinnsen@gmail.com 

Status: early work in progress.
